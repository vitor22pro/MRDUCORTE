# MR DU CORTE — Documentação do Site

## 1. Sobre o projeto

O *MR DU CORTE* é um site institucional para uma barbearia, desenvolvido com HTML, CSS e JavaScript.

O objetivo é apresentar a barbearia de maneira profissional, divulgar os serviços, mostrar os trabalhos realizados e facilitar o contato dos clientes para agendamento.

O projeto utiliza uma identidade visual moderna, com predominância das cores *preto e dourado*, transmitindo elegância e sofisticação.

## 2. Estrutura do projeto

O projeto está organizado da seguinte maneira:

text
MR-DU-CORTE/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
├── assets/
│   └── img/
│
└── README.md


### Descrição dos arquivos

- *index.html:* contém a estrutura e o conteúdo das páginas e seções do site.
- *css/style.css:* controla o visual, as cores, os tamanhos, os espaçamentos e a responsividade.
- *js/script.js:* responsável pelas interações e funcionalidades do site.
- *assets/img/:* pasta destinada às imagens, fotografias e identidade visual da barbearia.
- *README.md:* documentação com informações sobre o projeto e instruções de utilização.

## 3. Funcionalidades do site

### Página inicial
Apresenta a identidade da MR DU CORTE, com destaque para a barbearia e um botão de agendamento.

### Sobre a barbearia
Seção destinada à apresentação da empresa, sua proposta e seus diferenciais.

### Serviços e preços
Área para divulgar os serviços oferecidos e seus respectivos valores.

### Galeria de cortes
Espaço para exibir fotografias dos cortes realizados, permitindo que os clientes conheçam o trabalho do barbeiro.

### Localização
Seção destinada ao endereço da barbearia e à localização no mapa.

### Horário de funcionamento
Apresenta os dias e horários de atendimento.

### Agendamento pelo WhatsApp
O cliente pode clicar no botão de agendamento e ser direcionado diretamente para uma conversa no WhatsApp da barbearia.

*WhatsApp configurado:* (81) 98547-2176.

## 5. Como executar o projeto

1. Extraia o arquivo ZIP do projeto.
2. Abra a pasta MR-DU-CORTE.
3. Localize o arquivo index.html.
4. Clique duas vezes nele para abrir o site no navegador.

Também é possível utilizar o Visual Studio Code com a extensão Live Server para visualizar as alterações durante o desenvolvimento.

## 6. Como personalizar o site

### Alterar informações
Abra o arquivo index.html para modificar textos, títulos, serviços e informações apresentadas.

### Alterar cores e aparência
Abra css/style.css para modificar as cores, fontes, dimensões, espaçamentos e outros elementos visuais.

### Alterar WhatsApp
Abra js/script.js e localize a configuração do número de WhatsApp.

O número deve estar no formato internacional, sem espaços ou caracteres especiais:

5581985472176

### Alterar endereço e horários
Localize as configurações correspondentes no arquivo js/script.js e substitua os valores de exemplo pelas informações reais da barbearia.

### Adicionar fotografias
Coloque as fotografias na pasta assets/img/ e atualize os caminhos das imagens no HTML e no CSS para utilizar os arquivos locais.

## 7. Observações importantes

- Antes de publicar o site, atualize o endereço, os horários e os preços.
- Substitua as imagens de demonstração por fotografias reais da barbearia.
- Confira se o botão do WhatsApp está funcionando corretamente.
- Teste o site em computadores, tablets e celulares.
- As imagens externas utilizadas na versão inicial dependem de conexão com a internet.

## 8. Objetivo final

Entregar uma presença digital profissional para a *MR DU CORTE*, facilitando a divulgação dos serviços, fortalecendo a identidade da barbearia e tornando o agendamento mais simples e acessível para os clientes.
